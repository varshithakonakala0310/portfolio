# Varshitha Konakala — Portfolio

Personal portfolio website for **Varshitha Konakala**, Business Analyst and MSc Business Analytics graduate (Aston University).

**Design:** converted to a static website from the Canva template *"Red Cream Bold Modern Creative Portfolio Presentation"* by Studio Flare — cream background, bold red, oversized display typography, chunky borders, offset shadows and rotated sticker labels — with content and elements changed to match Varshitha's CV, dissertation and projects.

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files

- `index.html` — page content
- `styles.css` — all styling (responsive, reduced-motion support)
- `script.js` — mobile nav, scroll reveal, active nav highlighting

## Deployment

Static site, ready for GitHub Pages from the repository root on the `main` branch.
